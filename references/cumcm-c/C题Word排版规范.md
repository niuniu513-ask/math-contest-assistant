# C题 Word 排版规范

当届官方模板和赛区要求优先。本文件仅补充官方未统一规定的内部样式。

- 所有正文性文字统一黑色：标题、正文、公式、图表标题、页码、参考文献、脚注和超链接显示文字均为 `000000`；
- 中文正文宋体，英文和数字 Times New Roman；标题黑体，公式字体遵循公式编辑器但显示为黑色；
- 彩色只用于有数据区分意义的图表，灰度打印仍须可辨；
- 图题置于图下、表题置于表上；表格优先三线表；公式居中、编号右对齐；
- 使用样式控制标题和正文，不逐段手工拼格式；
- 禁止蓝色超链接、主题色标题、彩色强调文字和无意义底纹；
- 检查标题孤行、段落孤行、图表跨页截断、表头未重复、大片空白、越界和编号引用；
- Word 与 PDF 的内容、页码、公式、图表和参考文献必须一致。

最终先运行 `scripts/docx_style_audit.py`，再逐页渲染检查。审计不替代视觉检查。
