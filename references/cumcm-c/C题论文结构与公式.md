# C题论文结构与公式

## 正文结构

正文内部质量目标 25–30 页，服从当届官方上限。建议结构为：摘要；问题重述；问题分析；数据预处理与探索；假设与符号；逐问建模、求解、结果和验证；问题关联；模型比较与样本外验证；敏感性、稳健性和误差；评价、推广、结论；参考文献。

篇幅按证据分配，不机械平均。数据分析通常占 10%–15%，各问建模求解占 45%–55%，验证误差占 12%–18%。低于目标时依次补数据洞察、真实推导、数值算例、候选比较、样本外验证、误差和决策解释；禁止用目录、重复文字、空白、放大字号、拉伸图表和代码截图凑页。

## 推导链

完整论文通常有 20–35 个有效编号公式，但以模型闭合为准。每个核心模型覆盖：变量参数、原始关系、假设简化、目标/方程、主要约束、必要变换/线性化/离散化、参数获得、算法更新和验证指标。

正文应展示决定模型含义和可复现性的推导；冗长机械展开可放附录。拆分简单定义、重复总模型、未用于求解、后文未引用或与代码不一致的公式不计数。

## 图表与表格

完整论文通常有 12–18 幅有效图和 8–12 张核心表。覆盖数据理解、模型机制、核心结果、方案比较和验证即可，不机械凑类别。每项必须绑定主张、真实来源、关键数值和正文位置；删除后不损失论证的信息应合并或淘汰。流程图和技术路线图合计不应挤占结果证据。

图表解读直接写入论证，包含读数、原因和对模型或决策的意义；禁止批量套用固定句式。
