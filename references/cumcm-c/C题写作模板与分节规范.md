# C题写作模板与分节规范

## 写作总原则

论文按证据写，不按模板填空。所有数字、公式、图表和结论来自真实运行。模板负责保证结构与顺序，不负责替代模型推导。

## 章节结构

每个子问题采用双文件或等价结构：

```text
5.X.问题X的建立与求解
├── 5.X.1 分析与准备
└── 5.X.2 建模与求解
```

数据预处理集中在问题一；后续问题只写必要的字段、共享输入和误差传播，不重复整段清洗过程。

## 摘要

- 原则上一页，约 900 字；
- 问题段按题型分配篇幅：建模 30%-35%，分析 20%-25%，建议 10%-15%；
- 每问写必要的方法、处理和关键结果，不写检验细节与长篇公式；
- 编译后检查摘要页数，超页按比例压缩；
- 禁止摘要与结论数值不一致。

## 分析与准备

包含：

- 问题类型与目标；
- 输入、输出、难点和定位；
- 候选方法比较；
- 所选方法的真实依据。

算法比较不使用“优/良/中/差”一类无证据等级，必须记录真实指标、运行时间、稳定性、数据要求和失败点。

## 建模与求解

公式链至少覆盖：

```text
变量参数
→ 假设简化
→ 目标函数或主要方程
→ 约束或边界
→ 必要变换与推导
→ 参数来源
→ 求解方法
→ 验证指标
```

公式之间用文字串联，不孤立堆公式。变量说明紧跟在公式后。公式数量是预警，不是目标。优化模型必须完整写出目标函数、决策变量和约束条件。

## 模型检验

按题型选择：

- 预测/回归：交叉验证、R2、RMSE、MAE、MAPE；
- 分类：交叉验证、准确率、召回率、F1、混淆矩阵；
- 优化：约束可行性、最优界、基线比较、不同初始解；
- 评价：权重敏感性、排序稳定性；
- 仿真：极端情景、重复实验、收敛；
- 机理：量纲、守恒、极限情形。

敏感性分析必须列出变化参数、变化方向和结论是否改变。

## 表达规范

- 正文主要使用自然段落，不把每个结论写成分点模板；
- 假设、优缺点和必要清单可使用列表，但每条必须具体；
- 不滥用加粗；公式、图表和关键词不靠加堆砌吸引注意；
- 章节之间不人为加空页；
- 图表正文必须自然说明“读数、原因、模型含义”，不重复模板句。

## 参考文献与附录

- 每条文献必须在正文中引用；
- 不得保留未使用模板示例文献；
- 附录只放附件清单，且文件名必须能映射到项目实际交付文件；
- 程序、图表和结果与附录一致。
