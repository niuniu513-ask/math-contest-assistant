# 模型复杂度与基线

## 复杂度阶梯

| 等级 | 方法范围 | 使用条件 |
|---|---|---|
| L0 | 描述统计、直接计算、规则法 | 所有任务起点 |
| L1 | 线性模型、基础回归、插值、确定性规划 | 能表达题意时优先 |
| L2 | 非线性、多目标、时间序列、标准机器学习、蒙特卡洛 | L1 有可验证缺陷 |
| L3 | 随机/鲁棒优化、复杂仿真、集成学习、启发式算法 | L2 不能满足关键要求 |
| L4 | 深度学习、复杂贝叶斯、混合元启发式、多模型集成 | 数据、题意和实验收益均支持 |

每个子问题单独定级。组合模型按最高复杂度组件审计。原则上逐级升级；跳级必须证明中间层结构上不适用。

## 题型基线

| 题型 | 默认基线 |
|---|---|
| 预测 | 持久性预测、均值、线性趋势 |
| 回归 | 线性或正则化线性回归 |
| 分类 | 多数类、逻辑回归、浅层决策树 |
| 评价 | 原始指标排序、等权评分 |
| 优化 | 贪心可行解、线性松弛或确定性规划 |
| 时间序列 | 上一期值、季节性朴素法 |
| 聚类 | K-means 与简单距离规则 |
| 图论 | 最短路、最小生成树、基础网络指标 |
| 仿真 | 确定性平均参数或小规模手算实例 |
| 机理 | 守恒关系、极限情形和降阶模型 |
| 多目标 | 单目标极端解、加权和基线 |
| 决策 | 期望值决策或简单情景表 |
| 预测后优化 | 朴素预测加确定性优化 |
| 评价后决策 | 等权评分加阈值决策 |
| 聚类后预测 | 不聚类的全样本预测 |
| 降维后建模 | 原始变量正则化模型 |
| 不确定性优化 | 均值参数确定性方案 |
| 相关性建模 | 独立变量情景 |
| 多阶段规划 | 逐阶段独立或滚动基线 |
| 组合赋权 | 等权和单一客观赋权 |
| 集成学习 | 最优单模型 |
| 元启发式求解 | 贪心、松弛或标准求解器 |

## B1 门禁

每问记录题型、基线、输入边界、指标、命令、耗时、结果、可行性和已知失败点。指标必须在候选比较前确定。基线未真实运行、没有结果文件或失败点只靠主观判断时，B1 为 FAIL。

## 升级合同

升级必须回答：

1. 当前基线具体失败在哪里；
2. 新模型增加哪些变量、假设、超参数和计算成本；
3. 哪个预先确定的指标证明升级有效；
4. 改善是否覆盖复杂度、时间与解释成本；
5. 团队能否解释和复现。

M1 比较同口径的关键指标、样本外表现、约束可行性、稳定性、耗时、假设、超参数、解释性和复现难度。复杂模型不解决关键失败、只改善非关键指标或收益很小而成本陡增时回退。

基线决定模型选择或正文声称模型效果好时，正文必须展示对比；否则可放附录，但仍进入支撑材料和复现清单。
