# C题自主解题协议

## 定位

本协议用于全国大学生数学建模竞赛 C 题。C 题常见数据驱动、预测评价优化组合与多附件结构，但必须按题面识别，不以题号预设模型。

## 执行顺序

1. 读题面以理解附件字段与交付要求。
2. 在正式拆题和定模前完成数据审计、预处理与 D1。
3. 将每个子问题标注为预测、回归、分类、评价、优化、时间序列、聚类、图论、仿真、机理、多目标、决策或复合任务。
4. 运行最低复杂度基线并通过 B1。
5. 比较候选模型；复杂模型只有在修复基线关键缺陷且收益覆盖成本时才能成为主模型。
6. 先原型后全量，保存耗时、失败、最好可行解和恢复点。
7. 针对题型验证，建立主张—证据矩阵后写作。
8. 使用当届官方模板，完成内容、样式和逐页视觉检查。

## 禁止事项

- 不从题型字母直接选择模型。
- 不先写论文再补数据和结果。
- 不用获奖论文的模型组合替代当前数据诊断。
- 不为篇幅、公式或“创新性”保留无贡献模型。
- 不把预处理降格为格式转换。
- 不把支持集固定、降采样或均值替代包装为完整空间最优。

## 交付边界

完整交付包括论文、源代码、权威结果、题目指定模板、数据处理记录、基线结果、模型选择记录、复现清单和限制说明。获奖论文仅用于内部对标，不在正式稿暴露。
