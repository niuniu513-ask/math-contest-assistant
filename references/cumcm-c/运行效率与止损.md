# 运行效率与止损

完整流程原则上控制在四小时以内，但不是固定硬阈值，也不用于中断一个即将得到关键结论的任务。目标是让模型规模、求解实验和用户剩余时间互相匹配。

## 局部保护

- 单条命令设置合理超时；
- 无响应时间达到阈值时停止；
- 同一配置最多重试 3 次；
- 达到重试上限后必须改算法、改规模或改参数，不允许无信息重复；
- 长任务保存当前可行解、界、gap、日志和恢复点；
- 复杂模型尚未超过简单基线时不扩大规模；
- 预计继续运行不会改变模型选择或结论时停止。

## 提速顺序

```text
修正数据与约束
→ 使用成熟库和求解器
→ 向量化
→ 变量/特征削减
→ 问题分解
→ 暖启动
→ 合理降采样或情景压缩
```

任何方法都不能删掉题目核心约束，不能把局部支持集或均值结果包装为完整空间最优。

## 恢复

检查 `run-state.json` 中的阶段、检查点、产物哈希和错误信息。文件未变化的完成步骤不重复运行；失败后从最近有效检查点继续。
