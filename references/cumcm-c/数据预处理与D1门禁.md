# 数据预处理与 D1 门禁

## 目标

数据处理要产生可用于模型选择的证据，而不只是把 Excel 转成 CSV。原始文件只读，所有变换可追溯。

## 最小审计

- 文件、工作表、表头、首尾行、合并单元格、公式和单位；
- 字段类型、编码、类别取值、样本量及时间/空间范围；
- 缺失、重复、异常、冲突、非法值、精度和量纲；
- 训练、验证、预测边界及未来信息泄漏；
- 主键、连接关系和一对多膨胀；
- 题目指定输出模板的结构与静态单元格。

## 处理决策

每项处理记录：来源字段、发现、处理方法、依据、影响行数、处理前后统计、对模型与结论的可能影响、可逆方式。禁止无解释地填补缺失、删除异常、标准化或聚合。

参数按证据分级：A 为附件直接计算，B 为题设推导，C 为可追溯文献迁移，D 为情景假设。C/D 参数必须给出范围和敏感性计划。

## 探索分析

按当前数据选择必要分析，不设固定图数。分析必须回答至少一项模型决策问题，例如分布与尺度、非线性、共线性、时间趋势、空间异质性、类别不平衡、收益/成本结构、网络连通性或约束瓶颈。不能回答模型选择问题的图不进入 D1 证据。

## D1 通过条件

- 所有输入均有清单和哈希；
- 质量问题已处理或明确保留理由；
- 处理前后可追溯且关键统计一致可解释；
- 不存在未处理的时间泄漏、单位冲突和连接膨胀；
- 数据规模、有效信息和可辨识性已用于限制候选模型；
- 至少形成一组直接支持后续模型选择的数据发现；
- 规定产物存在且非空。

D1 失败时停留在 `data`。无结构化数据时，以题设数值、量纲、边界、初值和参数可辨识性报告替代文件级统计。
