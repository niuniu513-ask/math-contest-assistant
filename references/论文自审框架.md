# W1/W2 论文自审框架

## W1 证据大纲

- [ ] 每个子问题有直接回答题目的主张。
- [ ] 每个关键主张绑定权威结果字段、公式、表/图、代码和验证。
- [ ] 摘要拟用数字来自冻结结果，展示精度有依据。
- [ ] 因果、显著、最优、稳定、鲁棒等表述有相应证据。
- [ ] 局限、适用边界和失败情形与实验一致。
- [ ] 引用可追溯到原始出版页、标准或官方数据。
- [ ] 每个核心模型在 `.work/derivation-ledger.json` 中有现实映射、变量/单位、假设条件、逐步推导、数值示例、近似误差和验证。
- [ ] 优化模型完整列出目标和全部约束；算法模型有编号步骤及作用；统计/机器学习模型有预处理、特征、参数和指标依据。
- [ ] 后问明确写出继承的变量、公式、结果字段和误差传播，而非只写“基于上一问”。
- [ ] 获奖论文对标只保存在 `.work/benchmark-gap.json`，没有进入竞赛稿证据链。

## W2 内容一致性

- [ ] 题目全部子问和题目指定附件已覆盖。
- [ ] 摘要、正文、表、图、结论与权威结果一致。
- [ ] 符号、单位、公式、图表和引用编号连续且交叉引用正确。
- [ ] 公式和图表只为表达证据，不按往届样本凑数量。
- [ ] 没有占位符、示例数据、虚构试错、未核验引用或人工编写指标。
- [ ] 独立公式不用 `$$...$$`；编号全局连续，正文引用对应，变量/向量/矩阵/单位格式与定义一致。
- [ ] 每张正式图和核心表都有相邻的“趋势/特征—成因—启示”解读，并含可核对数值。
- [ ] 决策痕迹来自 `.work/decision-traces.json` 的真实实验或比较；没有随机植入或虚构团队对话。
- [ ] 正式竞赛稿不含同届/未来获奖论文编号、内部路径、门禁名称、对标说明或赛后答案。
- [ ] `paper_content_audit.py --strict` 退出码为 0。
- [ ] 有效且不重复的全局连续编号公式不少于 15 个，每式均有推导或作用解释；图文件真实可读且非装饰图不少于 12 幅；含作者/机构、题名、来源与年份的真实领域文献不少于 8 条。
- [ ] 图内文字已抽检：无乱码/缺字，无英文列名/变量名直接进图例；语言与论文一致且可读（中文题可中英混用）。
- [ ] 至少一个关键模型已用两种原理独立、证据文件不同的方法做定量交叉验证；若采用例外，极端工况、失效边界和证据齐全。
- [ ] 优化章节明确区分物理目标与实际目标，给出数学关系、直接物理目标运行结果及 Pareto/多目标对比证据。
- [ ] 两个不同连续参数、两种模型假设和两种边界规则均有结果摘要及项目内证据；非 `±20%` 取值有物理可行域说明。
- [ ] 每项硬约束按上限、下限、绝对值或双侧类型正确计算裕度；低于 1% 的项有警示、误差讨论和收紧约束重求解证据。
- [ ] `.work/benchmark-gap.json` 的动态禁漏词在规范化 Markdown 和最终 DOCX 中均零命中；最终 DOCX 已作为严格审计输入，未省略。

## W2 官方格式与技术

- [ ] 已记录目标竞赛、届次、官方规则和模板来源；未把历史经验当官方要求。
- [ ] Word 公式可编辑、表格可编辑，结构校验和渲染抽检通过。
- [ ] LaTeX 真实编译，日志、引用、字体、页面、图片和资源哈希检查通过。
- [ ] 同时生成两种格式时共用同一证据源并逐项核对差异。
- [ ] 论文篇幅符合当届官方规则与国赛内部质量档（正文 20~25 页）；未把官方上限当目标、未注水。
- [ ] 已记录正文起始页、附件起始页、主体页数、附件页数和总页数。
- [ ] 篇幅来自完整推导、结果和验证，没有重复文字、异常留白、字号放大或图表拉伸。
- [ ] 每个核心模型至少有一幅必要演示图/实例图，并另有直接回答题目的结果证据。
- [ ] 门禁证据已记录；无独立质检时标记 `LIMITED`。
