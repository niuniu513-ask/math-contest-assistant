# P1/P2 编程质检清单

## P1

- [ ] 最小命令从 `PROJECT_ROOT` 可运行且退出码为 0。
- [ ] 使用真实输入或结构等价实例，输入到输出可追溯。
- [ ] 单位、数量级、关键约束和边界符合模型合同。
- [ ] 至少一个手算、极限、基线或独立实现核对通过。

## P2

- [ ] 全部子问题和题目指定结果模板已覆盖。
- [ ] 代码未硬编码本应读取的附件、结果或统计指标。
- [ ] 随机种子、参数、容差、依赖、输入 SHA-256 和唯一命令已记录。
- [ ] 训练/验证、时序切分、数值收敛、优化可行性或随机误差检查与模型类型匹配。
- [ ] 灵敏度范围和展示精度有题设、数据、物理或文献依据。
- [ ] Python 或 MATLAB 主路线有唯一可运行入口，版本、依赖或工具箱已记录。
- [ ] 每个核心模型至少有一幅由代码生成的必要演示图/实例图，并另有结果图或结果表回答题目。
- [ ] 图表支撑明确结论，数据、单位、尺度、图例和题注正确；已实际查看最终尺寸。
- [ ] 结果表、图和论文拟用数字来自同一权威输出。
- [ ] 清理缓存后唯一复现命令可重建关键结果。
- [ ] 门禁证据已记录；独立质检不可用时状态为 `LIMITED`，未伪称 `PASS`。
