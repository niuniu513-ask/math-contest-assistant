# 可视化规范

## 1. 图表契约

生成每张图前记录：对应子问题、核心结论、权威数据路径、变量与单位、统计口径、图型、目标尺寸和正文落点。无法写出核心结论的图通常不应生成。

## 2. 按证据选图

| 证据目标 | 常用图型 |
|---|---|
| 分布与异常 | 直方/密度、ECDF、箱线/小提琴加原始点 |
| 时间变化 | 折线、区间带、事件标记；避免未来信息混入 |
| 关系与拟合 | 散点、拟合线、置信/预测区间、残差图 |
| 分类性能 | 混淆矩阵、ROC/PR、校准图；类别不平衡时优先 PR |
| 优化过程 | 收敛、可行性、Pareto 前沿、方案对比 |
| 空间/网络 | 等比例地图、路径、网络图；说明坐标和投影 |
| 不确定性 | 区间图、分布、扇形图、情景对比 |

获奖论文实读中最常见的高价值叙事角色包括：机制/几何图、流程/依赖图、处理前后对比、诊断图和决策结果图。先确定图的叙事角色，再选具体图型；详见 `获奖论文实读方法论.md`。

每个核心模型至少安排一幅必要演示图或实例图来说明模型如何工作，并另用结果图或结果表回答题目。演示图优先采用可复现的小算例、几何关系、状态演化、局部网络、处理前后或迭代过程，不能使用素材式装饰图替代。

原始数据图、模型过程图和最终结果图是可选分类，不是固定配额。只生成能支持正文主张或验证模型的图。

## 3. 统计与视觉真实性

- 统计量、区间、p 值和样本量由当前代码计算；置信区间不得用标准差冒充。
- 柱状图通常从零开始；截断坐标必须显式标记并说明。
- 不用 3D 柱、饼图、`jet/rainbow`、无说明双 Y 轴或装饰性面积编码。
- 3D 网络或几何图仅用于表达真实三维结构，并同时提供可读的 2D 投影、坐标或定量表；不把 3D 透视图作为精确读数的唯一证据。
- 连续变量使用连续色图，分类变量使用离散且色觉友好的颜色；同一变量跨图语义一致。
- 稠密曲线不逐点加大标记；图例不遮挡数据，必要时直接标注。
- 标题、坐标轴、单位、图例、色条、面板编号和图注完整，但不把整段论文塞入图内。

## 4. 版面与导出

先按论文中的最终物理尺寸绘制，再设置字体、线宽和标记。优先保存 SVG/PDF 可编辑版本和 ≥300 DPI PNG；官方模板限制格式时遵循模板。

```powershell
python "<SKILL_ROOT>/scripts/figure_audit.py" "<PROJECT_ROOT>/figures" --no-category-check --strict
```

只有项目质量计划明确要求 `raw/process/result` 三类和各子问题覆盖时使用：

```powershell
python "<SKILL_ROOT>/scripts/figure_audit.py" "<PROJECT_ROOT>/figures" `
  --require-categories --min-per-category 1 --questions q1 q2 q3 --strict
```

## 5. 最终视觉检查

自动审计后实际打开彩色与灰度图，在预计显示尺寸下检查：缺字、负号/希腊字母、裁切、重叠、空白、尺度、颜色可辨性、误差棒、边界和跨图一致性。发现问题回到源代码重绘，不直接涂改 PNG。

用一句话复述第一视觉结论；若与图表契约不一致，重选图型或布局。
