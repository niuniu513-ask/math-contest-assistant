# 图表选择与避坑

只有在需要选择图型、审查用户指定图型或排查成图问题时加载本文件。先看数据结构和论证目标，再考虑风格。

## 选图四问

1. 图要表达分布、比较、关系、趋势、构成、空间结构，还是模型性能？
2. 变量是连续、分类、有序、时间、空间还是矩阵？点之间是否真的存在连续关系？
3. 每组样本量、缺失、偏态、异常值和重复测量结构如何？
4. 需要展示原始观测、汇总统计、不确定性，还是三者同时展示？

## 数学建模场景速查

| 任务 | 推荐图型 | 必须补充的信息 |
|---|---|---|
| 单变量分布 | 直方图/KDE、ECDF、箱线或小提琴并叠加原始点 | n、分箱或核参数、异常值规则 |
| 分组比较 | 点图、箱线/小提琴 + 原始点；样本充分且分布合适时可用均值 + 区间 | 中心统计量、区间类型、检验与效应量 |
| 两连续变量关系 | 散点 + 合理拟合与区间；大样本用透明度、hexbin 或密度 | 拟合假设、相关/回归统计、异常点处理 |
| 时间或剂量趋势 | 折线/阶梯图 + 区间；重复测量可增加个体轨迹候选图 | 时间顺序、聚合方式、区间定义 |
| 构成比例 | 排序条形图、堆叠条形图或面积图 | 分母、总和约束、类别排序 |
| 相关矩阵 | 发散热力图，必要时聚类排序 | 相关系数类型、缺失处理、色标范围 |
| 优化过程 | 目标值/最优值收敛、可行率、约束残差、Pareto 前沿 | 迭代数、停止条件、可行性定义 |
| 预测模型 | 真实值-预测值、残差、校准、误差分布、时序回测 | 数据划分、指标定义、种子/折数与区间 |
| 分类模型 | 混淆矩阵、ROC/PR、阈值-指标曲线、校准曲线 | 类别不平衡、阈值、宏/微平均口径 |
| 评价/排名 | 排名点图、带权贡献图、敏感性图 | 权重来源、归一化方法、稳定性 |
| 空间/网络 | 地图、轨迹、网络结构和局部放大 | 坐标系、比例尺、方向、图例 |
| 物理模型 | 理论-实验对照、残差、参数敏感性、近似误差随条件变化 | 单位、边界条件、近似适用域 |

图型只是起点。同一批数据可以围绕不同结论生成多张候选图，不因数据重复就机械删除；但每张图必须有清楚的用途和正确的视觉语义。

## 主动拦截的问题

- **小样本只画均值柱**：会隐藏样本量和分布。优先展示每个观测点，并根据样本结构选择区间或非参数摘要。
- **无关量使用双 Y 轴**：轴范围可人为制造同步关系。优先拆成共享 x 的上下子图，或用关系散点图；确有物理耦合且必须双轴时说明尺度与理由。
- **离散类别被折线连接**：会暗示不存在的连续过渡。改用点图、条形图或箱线图；有序类别的引导线需在图注声明。
- **稀疏分组率被折线连成锯齿**：按周、批次或小组计算的经验比例若样本量变化大，连线会把抽样波动伪装成连续趋势。优先画点估计 + 二项分布区间，并同时给出各组 `n`；只有时间连续性和聚合口径稳定时才连线。
- **饼图、3D 柱状或装饰性三维表面**：角度和透视不利于精确比较。优先排序条形图、堆叠图、热力图或等高线图。
- **坐标截断造成视觉夸张**：条形图应有可解释的零基线；其他图若缩小范围，需保留足够边距并清楚标示截断、对数或基准。
- **少量点估计使用巨型柱状图**：三五个推荐值、排名或参数估计更适合排序点图、棒棒糖图或点 + 区间图；柱纹理和粗边框不能替代不确定性。
- **连续颜色没有 colorbar**：读者无法还原数值。增加变量名、单位和固定的 `vmin/vmax`；跨图比较时保持色标一致。
- **已标数值的 2×2 混淆矩阵仍放 colorbar**：颜色只承担辅助分组时，直接标注计数与行/列百分比即可；冗余色条会挤压主图。类别不平衡时还要给出阈值、阳性率和 PR 基线。
- **仅靠红绿或大量相近颜色区分类别**：改用色觉友好配色，并增加线型、标记或纹理。
- **所有面板机械等宽等高**：主结论和辅助证据的信息量不同却平分画布，会产生仪表盘感。先声明主面板，再按证据权重和纵横比使用非对称布局；只有同尺度、同权重比较才等分。
- **长标题和大图例抢走第一视觉焦点**：面板内只保留短标题，完整结论写入图注；三条以内曲线优先直接标注，四至五项使用共享图外图例，更多系列考虑分面或突出主系列。
- **稠密曲线逐点使用大标记**：会形成彩色绳结并遮蔽趋势。观测点密集时取消 marker，或用 `markevery` 只标出少量代表位置。
- **特征重要性用密集纹理粗柱**：优先排序点图或细条形图，并展示跨折/重复实验的不确定性；纹理仅在灰度打印确需区分类别时稀疏使用。
- **误差与显著性来源不明**：图注必须给出 n、区间、检验、校正和比较对象；优先同时报告效应量，不能只堆星号。
- **图例、文字或面板编号遮挡/错位**：调整布局、直接标注或图外图例，重新渲染后再检查，不能只看源代码猜测。
- **导出为截图、JPEG 或低 DPI PNG**：回到绘图代码导出 SVG + 300 DPI PNG，并检查 SVG 文本可编辑。

若用户坚持使用存在明显误导风险的图型，先说明具体风险和可执行替代方案；用户确认后可以保留为额外候选图，但不得把它作为唯一证据，也不得隐去风险说明。

## 成图视觉检查

- 文字和符号完整，无方框、乱码、重叠或裁切；
- 图例不压住数据，长刻度仍可读；
- 多面板标签、边距、字体、颜色和共享尺度一致；
- 第一视觉焦点是核心数据关系而不是标题、图例、色条、纹理或大片空白；
- 主面板面积与证据权重匹配，辅助面板确实补充独立证据；
- 灰度下仍能靠线型、标记或明度分辨关键系列；
- 坐标范围没有切掉点、误差棒、置信带或物理边界；
- 图在论文预计尺寸下仍可读，放大和缩小都没有暴露格式错误。
