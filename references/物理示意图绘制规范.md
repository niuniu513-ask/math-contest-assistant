# 物理示意图绘制规范（PowerPoint + python-pptx）

> 物理示意图（坐标/光线/矢量/角度/受力/场/几何布局）用 **PowerPoint + python-pptx 以代码生成**，
> 可复现、可纳入复现清单。工具选择理由见下文"为什么是 PPT"。
> 模板脚本：`scripts/schematic_pptx.py`；数据图/流程图仍按既定规范（求解语言 / MATLAB）。

## 一、为什么是 PowerPoint 而非 Visio

| 判据 | PowerPoint + python-pptx | Visio |
|---|---|---|
| 物理示意图=几何关系示意（光/矢/角/场） | 自由绘制天然适配 | 面向工程图/流程图，画示意插图笨重 |
| 可编程、可复现（skill 代码纪律） | python-pptx 成熟，坐标精确 | 无干净 Python 库，COM 繁琐 |
| 环境 | Office 自带 | 单独授权（多数环境未装） |
| 输出 | PPTX（矢量源）+ PNG(300dpi) | 可导出但成本高 |
| skill 已覆盖 | 流程图/技术路线已由 MATLAB 承担 | Visio 无增量价值 |

## 二、何时用物理示意图

- 坐标系/几何关系：太阳高度角、方位角、入射/反射、镜场布局、受力、磁场/电场、结构示意。
- 判据：若图是"解释物理场景的示意"而非"严格工程图/数据图"，用 PPT；数据图用求解语言；流程图/技术路线用 MATLAB。

## 三、绘制规范

### 几何正确性（最重要）
- 反射/矢量关系按真实几何计算：法向 n = normalize(unit(入射) + unit(反射))，镜面倾角 = 法向角 − 90°；不得凭感觉画角度。
- 光线、法线、角度弧必须从正确锚点出发；角度用 arc 原语画在对应两条线之间。
- 使用逻辑坐标（x 右、y 上），模板自动映射到页面；画布范围给定后所有元素须落在其内。

### 视觉规范
- 配色用 `plot_style.PALETTE` 或一套内聚色（如示例：太阳#E69F00、入射光同色、反射光#009E73、法向#D55E00、结构#37474F）。
- 线宽：主干光线 2.0–2.5pt，法向/辅助线 1.0–1.5pt；法向用虚线（dash）。
- 标注：字号 9–11pt，紧贴对应线/点，避免与线条相交；必要时给出数值（如 αs≈53°、θ≈49°）。
- 输出：PPTX 为可编辑矢量源；导出 PNG ≥300DPI（模板 COM 导出约 300dpi）；需 EMF/SVG 时在 PowerPoint 中手动另存。

### 复用与复现
- 每个物理示意图用一个独立脚本/函数，参数集中；随机与几何量从模型合同传入。
- 登记到 `figure_manifest` 与复现清单；图题按"图X-Y 说明"。

## 四、模板用法速查

```python
from schematic_pptx import Schematic
s = Schematic(xlim=(0,12), ylim=(0,6))
s.axes((0.8,0.5),(3.2,0.5),(0.8,2.6), xlabel="x (m)", ylabel="y (m)")
s.arrow((2.3,4.9),(5.2,1.0), color="E69F00", width=2.5, label="入射光")
s.ray((5.2,1.0), 128, length=3, color="009E73")     # 沿 128° 方向
s.arc((5.2,1.0), 0.9, 79, 127, color="6A5ACD", label="θ")
s.mirror((5.2,1.0), 2.4, angle_deg=-11.3, label="定日镜")
s.tower((9.5,0.3), 3.2, width=0.5, label="吸收塔")
s.circle((9.5,3.5), 0.35, fill="D55E00")
s.text((0.6,0.1), "图3-1 塔式光热定日镜反射几何示意", bold=True)
s.save("示意图.pptx", export_png=True)
```

原语：`line / arrow / ray / axis / axes / arc / mirror / tower / circle / text`。

## 五、依赖与降级

- `pip install python-pptx`（生成 pptx，必需）；`pip install pywin32`（导出 PNG，可选）。
- 无 PowerPoint 环境：脚本仍可生成 PPTX，导出 PNG 标记 `BLOCKED`，不伪造图片。
