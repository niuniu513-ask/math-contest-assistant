# 赛题与获奖论文语料证据使用指南

需要联网补充当届规则、数据说明、理论来源或软件文档时，先加载 `web-access`。搜索页和聚合摘要只用于发现来源；最终证据必须尽量落到主办方、数据发布机构、原始论文出版页或官方文档，并记录 URL、访问日期、版本/发布日期、具体定位和下载文件哈希。

## 1. 可用语料

工作区可能包含历年赛题、获奖论文、Word/LaTeX 模板和课程代码。它们是可选增强资源，不是技能运行的必需路径。先在 `PROJECT_ROOT` 同级和用户指定目录发现资源；找不到时使用用户当前题目继续。

发现同级 `B站配套资料（晴天）` 时，使用 `../assets/08-晴天资料方法卡.md` 做方法发现，再按需打开对应编号目录的讲义和 Python/MATLAB 实例。课程示例仅用于理解公式、接口和演示方式，不作为当前题的模型正确性或结果证据。

`contest-questions-database.md` 是检索索引，必须回到原题核对。`award-paper-patterns*.md` 是观察性摘要，不能替代原论文。课程代码用于理解实现方式，必须重新验证后才能用于当前题。

首次使用本地大语料时生成轻量清单；默认不计算 5GB 语料的全文哈希：

```powershell
python "<SKILL_ROOT>/scripts/corpus_inventory.py" `
  --questions-root "<历年赛题目录>" --papers-root "<获奖论文目录>" `
  --latex-root "<LaTeX模板目录>" --word-root "<Word模板目录>" `
  --output "<PROJECT_ROOT>/.work/corpus-inventory.json"
```

## 2. 证据等级

| 等级 | 来源 | 可用于 |
|---|---|---|
| A | 当届官方规则、题目、附件、模板 | 硬约束、输入、输出、格式 |
| B | 原始学术论文、标准、官方数据 | 理论、参数范围、验证依据 |
| C | 往届原题与完整获奖论文 | 相似结构、常见风险、表达参考 |
| D | 二次总结、课程资料、博客 | 候选启发，必须再验证 |

冲突时按 A → B → C → D。任何“必须”都应能追溯到 A 级来源或通用真实性/可复现要求。

## 3. 检索流程

1. 从当前题提取领域、数学结构、数据形态、决策类型和验证难点。
2. 在赛题索引中找 2–5 个结构相似题，不只按题号字母或关键词匹配。
3. 回读原题，记录可迁移结构与不可迁移差异。
4. 只在需要时读取对应获奖论文的相关章节；记录年份、题号、论文编号、页码和用途。
5. 把可迁移内容写成候选，不直接写入当前题结论。

## 4. 禁止外推

- 不从摘要或前两页推断全文图表数、公式数、模型数或篇幅。
- 不把少量获奖样本的共性写成竞赛硬规则。
- 不因论文保留 5–7 位小数就强制当前结果采用相同精度。
- 不因论文使用多个算法就强制堆叠 3–5 个算法。
- 不复制往届论文的数值、结论、错误、图片或文字。
- 不把“优秀论文展示”自动解释为唯一最优方法。

## 5. 当前语料已知问题

- 赛题主目录目前可见年份止于 2024，名称中的“1992–2025”不能证明含 2025 原题。
- 2025 获奖论文目录内混入了一份完整历年赛题目录副本，建立索引时必须排除嵌套重复。
- 一些旧题为 `.doc`、`.rar`、BMP 或扫描 PDF，需要格式降级和完整性核对。
- 现有 2025 分析报告仅抽取 7 篇论文前两页；其中图表数量为估计值，不得作为门禁。
- 现有资料可能带第三方水印或再分发信息；仅作内部研究，引用时回到官方或原始出版来源。
- 同届或未来获奖论文不得出现在正式竞赛稿的正文、脚注和参考文献中；内部样本编号、文件路径、对标结论和赛后答案也不得泄漏。需要理论依据时回到原始论文、教材、标准、官方数据或软件文档。
