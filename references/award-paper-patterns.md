# 国赛获奖论文共性规律与写作范式

> **证据边界**：这是样本观察，不是官方规则。图表数、公式数、参数扰动范围、摘要结构和章节形式只能用作候选写作参考；当前题必须由官方规则、题目复杂度和 Claim–Evidence Matrix 决定。表中“必须”等措辞只描述原分析者的建议，不构成本 Skill 的硬门禁。

> 基于 2023 年国赛 A/B/C/D/E 题共 14 篇优秀获奖论文全文深度分析提炼。
> 覆盖物理工程型(A)、几何优化型(B)、数据驱动型(C)、排程规划型(D)、时序分析型(E)五种典型赛题。

---

## 一、获奖论文的 8 大共性特征

### 1. 摘要即"微缩论文"——数值密度极高

| 维度 | 规律 | 证据 |
|------|------|------|
| 结构 | "背景一句话 → 逐题方法+数值结果 → 结论" | 14/14 篇均如此 |
| 数值 | 每个问题至少给出 2-3 个核心数字 | 效率η、功率E、利润、利用率等 |
| 长度 | 300-500 字，半页以内 | A题偏400字，C题偏500字 |
| 关键词 | 问题领域 + 核心方法 + 算法名称 + 评价指标 | 4-6个 |

**摘要写作模板：**
```
[一句话定位问题本质]。针对问题一，本文采用[方法A]，建立[模型A]，
得到[核心数值结果1]。针对问题二，在问题一基础上引入[扩展条件]，
采用[方法B]求解，得到[核心数值结果2]。针对问题三，考虑[复杂约束]，
采用[方法C]优化，得到[核心数值结果3]。本文模型[一句话评价]。

关键词：关键词1；关键词2；关键词3；关键词4；关键词5
```

**关键原则：**
- 用"本文"而非"我们"
- 每问必给具体数值（精确到小数点后至少1位）
- 方法名称直接写出（如"遗传算法""SARIMA""NSGA-II"）
- 不写冗长背景，一句话切入

### 2. 问题分析独立成章——必含技术路线图

**14篇论文全部设有独立的"问题分析"章节**，且包含至少一张总体技术路线图。

**问题分析的写作模式：**
```
问题分析章节结构：
├── 总体分析（1段，概括问题本质和技术路线）
├── 问题一分析（数学本质 + 拟用方法 + 逻辑链）
├── 问题二分析（在问题一基础上的扩展）
├── 问题三分析（进一步复杂化）
└── [总体技术路线图/流程图]
```

**数学本质提取的通用方法：**
1. 识别物理量/业务量之间的因果链
2. 建立统一的坐标系或变量体系
3. 将连续过程离散化（如12月×5时点=60个代表时刻）
4. 明确目标函数和约束条件
5. 分析问题的优化层次（单目标→多目标→分组优化）

**引出建模思路的模式：**
- 先分析问题难点（"非线性、多变量耦合"），再引出对应方法
- 先指出搜索空间特征（"高维连续"），再选择算法
- 先做数据特征检验（正态性/周期性），再选模型

### 3. 模型建立——公式推导详尽且编号连续

| 指标 | 范围 | 说明 |
|------|------|------|
| 编号公式数 | 20-60个 | A题最多(30-60)，C/D/E题偏少(20-30) |
| 模型假设 | 4-9条 | 每条附一句话合理性说明 |
| 符号说明 | 表格式 | 含符号、含义、单位三列 |

**公式推导的层次模式：**
```
第一步：定义基本量（坐标/变量/参数）
  → 编号(1)(2)...
第二步：建立核心关系（物理定律/统计关系）
  → 编号(3)(4)...
第三步：推导中间变量（效率因子/特征函数）
  → 编号(5)(6)...
第四步：得到最终模型（目标函数/约束方程）
  → 编号(N)
```

**模型假设的写法规律：**
- 每条以"假设..."开头，简洁明确
- 按重要性排列（影响大的在前）
- 覆盖四个方面：物理简化 + 环境条件 + 参数恒定 + 边界条件
- 每条假设后续都应在模型中被使用或被讨论其影响

**符号说明表的规范：**
- 必须用表格（三线表），不能用行内文字
- 列：符号、含义、单位（可选：备注）
- 符号按出现顺序或逻辑类别排列
- 单位使用国际标准（m, m², kW/m², rad等）
- 下标规范：i表示编号, j表示时刻/批次等

### 4. 求解与结果——"表格+图+分析"三位一体

**每个子问题的结果必须三重展示：**

| 展示方式 | 作用 | 规范 |
|---------|------|------|
| 表格 | 精确数据呈现 | 三线表，编号连续，数值小数点对齐 |
| 图表 | 趋势/关系可视化 | 矢量格式，图题在下方，表题在上方 |
| 文字分析 | 解释规律和物理意义 | 指出极值、对称性、单调性等 |

**算法描述的标准方式：**
```
Step 1: [初始化] — 给出初始参数和起点
Step 2: [核心计算] — 描述主要计算逻辑
Step 3: [判断/更新] — 描述判断条件和更新规则
Step 4: [终止条件] — 给出收敛/终止标准
Step 5: [输出] — 说明输出内容
```

**结果分析的深度要求：**
- 不止于"给出数字"，必须包含"解释+对比+洞察"
- 分析变化规律（如"6月最高、12月最低，与太阳高度角变化一致"）
- 对比不同方案/参数的差异
- 指出结果的物理/业务含义

### 5. 灵敏度分析——获奖的必要条件

**A/B题：必须有独立的灵敏度分析章节**
- 选定2-3个关键参数
- 设定变化范围（通常±20%）
- 固定其他参数，逐个分析
- 绘制参数-输出曲线图
- **图中必须标注约束阈值线**（如10%、20%覆盖率虚线）
- 给出结论：哪个参数影响最大

**C/D/E题：灵敏度分析可隐含在模型比较中**
- 通过参数遍历展示敏感性（如D题遍历x=30~60）
- 通过多方法对比展示稳健性（如E题M-K+Fisher双重验证）
- 但**显式设置灵敏度分析章节是加分项**

**灵敏度分析模板：**
```
灵敏度分析章节结构：
1. 选定关键参数（2-3个，选对结果影响最大的）
2. 设定变化范围（±5%/±10%/±20%，分5个水平）
3. 固定其他参数，逐个变化目标参数
4. 绘制参数-输出曲线图（含阈值线/基准线）
5. 计算灵敏度系数 = (Δ输出/输出) / (Δ参数/参数)
6. 结论：参数敏感度排序 + 模型稳健性判断
```

### 6. 模型评价——"优点→缺点→推广"三段式

**14篇论文均采用标准三段式结构：**

**优点写法（3-5条）：**
- 从模型精度角度："模型考虑了完整的物理过程，计算精度高"
- 从算法效率角度："算法收敛速度快，计算效率高"
- 从通用性角度："模型通用性强，可推广至其他同类问题"

**缺点写法（2-3条，诚实但不自贬）：**
- 从计算量角度："XX计算采用离散化方法，计算量较大"
- 从假设局限角度："未考虑XX因素的影响"
- 从数据限制角度："数据量有限，部分拟合精度有待提升"

**推广写法（2-4句话）：**
- 指向同类问题的其他应用场景
- 指向不同参数/条件下的扩展
- 简短，不展开论述

### 7. 论文整体结构——篇幅与数量规律

**篇幅分布（以总页数20-25页为例）：**

| 部分 | 占比 | 页数 |
|------|------|------|
| 摘要 | 5% | 1页 |
| 问题重述与分析 | 10% | 2-3页 |
| 模型假设与符号说明 | 5% | 1页 |
| 各问题建模与求解 | 50-60% | 10-15页 |
| 灵敏度分析 | 5% | 1-2页 |
| 模型评价与推广 | 5% | 1页 |
| 参考文献 | 2% | 0.5页 |
| 附录（代码） | 3-8% | 1-5页 |

**图表与公式数量规律：**

| 指标 | 范围 | 说明 |
|------|------|------|
| 图数量 | 12-35张 | A/C题偏多，D题偏少 |
| 表数量 | 4-15张 | D题表格最多（排程表） |
| 图表总数 | 25-45个 | 图多于表，约2:1 |
| 编号公式 | 20-60个 | A题最多 |
| 参考文献 | 4-10篇 | 必含国标/经典教材/算法文献 |

### 8. 代码附录——完整可运行

**14篇论文均附完整代码**，特点：
- 代码可独立运行（含数据读取、计算、绘图全流程）
- 使用中文注释说明每段功能
- 函数有输入输出说明
- 代码量聚焦核心算法，不宜过大
- MATLAB为主，Python日益增多，部分论文用R/LINGO

## 二、分题型的获奖论文模式

### A题（物理/工程连续型）—— 以2023定日镜场为代表

**建模流程模式：**
```
坐标系建立 → 向量运算(入射光/反射光/法向量)
→ 效率分解(η = η₁ × η₂ × η₃ × η₄ × η₅)
→ 功率计算(E = DNI × A × η)
→ 优化模型(max η, s.t. 约束条件)
→ 算法选择(网格搜索/遗传算法/三分法)
→ 灵敏度验证
```

**A题特有规律：**
- 公式推导最详尽（30-60个编号公式）
- 必有坐标系示意图和镜场/装置布局图
- 灵敏度分析是标配（分析镜面尺寸、塔位置等参数）
- 常用MATLAB，部分用Python（numpy向量化计算）
- 散点图展示布局 + 热力图展示效率分布 + 3D可视化

**A题算法选择策略：**
| 问题特征 | 推荐算法 |
|---------|---------|
| 直接计算（问题一） | 解析公式直接求解 |
| 低维优化（问题二） | 三分法搜索/参数扫描/坐标轮换 |
| 高维优化（问题二） | 遗传算法 |
| 分组优化（问题三） | 分层搜索/遍历优化 |

### B题（离散/几何优化型）—— 以2023多波束测线为代表

**建模流程模式：**
```
几何关系分析 → 基本公式推导(正弦定理/坐标变换)
→ 覆盖宽度/效率计算 → 约束优化建模
→ 算法求解(模拟退火/粒子群/迭代递推)
→ 灵敏度分析(双参数扫描+阈值虚线)
```

**B题特有规律：**
- 几何推导为核心（正弦定理、三角函数、坐标变换）
- 从2D平面到3D空间的递进建模
- 优化问题必有约束条件（覆盖率10%~20%等）
- 灵敏度分析必须画图且标注阈值虚线
- 参考文献必须引用国标（如GB 12327-1998海道测量规范）
- 结果展示含俯视图/示意图/等高线图

### C题（数据驱动/经管型）—— 以2023蔬菜定价为代表

**建模流程模式（四层递进）：**
```
第一层：分布检验/数据探索（K-S检验/Shapiro-Wilk/偏度峰度）
  ↓ 根据数据特征选择方法
第二层：相关性/关联分析（Spearman/FP-Growth/PCA）
  ↓ 提取特征关系
第三层：预测建模（LSTM/Prophet/ARIMA/VAR/Bayesian）
  ↓ 模型比较选最优
第四层：优化决策（NSGA-II/模拟退火/MIQP/整数规划）
  ↓ 输出最优方案
```

**C题特有规律：**
- 数据清洗是第一步（IQR异常值剔除、零膨胀处理、缺失值填充）
- **方法选择必须由数据特征驱动**（非正态→Spearman，周期性→LSTM/Prophet）
- **必须比较多个模型后选最优**（如ARIMA vs Prophet，LSTM vs BP）
- 多目标优化用NSGA-II求Pareto前沿
- 灵敏度分析聚焦价格弹性、成本变动等经济参数
- 图表最丰富（20-26张图），含热力图、Pareto前沿图、ACF/PACF图
- 代码附录最完整（Python为主，含数据处理+建模+优化全流程）

**C题数据处理标准流程：**
```
1. 数据清洗：IQR异常值剔除 + 缺失值填充 + 退货标记处理
2. 数据聚合：单品→品类，日→周/月，区分销售/退货
3. 分布检验：Shapiro-Wilk/K-S检验 → 决定参数/非参数方法
4. 特征工程：构造季节性特征、节假日效应、价格弹性等
5. 模型比较：至少对比2个模型，给出R²/MAE/RMSE
6. 优化求解：基于预测结果建立整数规划/多目标优化
```

### D题（排程/规划型）—— 以2023圈养湖羊为代表

**建模流程模式：**
```
繁殖/生产周期分析 → 阶段离散化(配种/怀孕/哺乳/休息)
→ 0-1整数规划建模(阶段占用状态α_{ij}(t))
→ 确定性求解(遍历/参数化) → 随机扩展(概率分布+分段函数)
→ 排程表输出
```

**D题特有规律：**
- 核心是0-1整数规划，用变量描述阶段占用状态
- 时间离散化为天（t=1,2,...,T），每天计算并验证约束
- 问题间递进：确定性→带约束优化→随机/不确定排程
- 结果以排程表/甘特表为主要展示形式
- 灵敏度分析可通过参数遍历隐含体现
- 实用性强，结果直接给出可操作的排程方案

### E题（时序/环境型）—— 以2023黄河水沙为代表

**建模流程模式：**
```
数据预处理 → 回归分析(含沙量与流量/水位关系)
→ 突变检测(M-K检验+Fisher验证) → 季节性分解
→ 长程相关性分析(R/S分析/Hurst指数)
→ 预测建模(SARIMA/正弦拟合/GM(1,1)) → 优化决策(0-1规划)
```

**E题特有规律：**
- M-K检验是突变检测的核心方法，辅以Fisher检验交叉验证
- 时间序列分析需先做ADF平稳性检验，再用ACF/PACF定阶
- 多方法交叉验证增强可信度（M-K+Fisher，SARIMA+小波分析）
- R/S分析(Hurst指数)判断序列的长程相关性
- 图表密度极高（28-41张图），含UF/UB曲线、小波等值线图、双对数图
- 参考文献涵盖方法论文献（M-K检验、R/S分析等）

## 三、写作技巧与规范

### 3.1 过渡句体系

**段落间过渡（14篇论文高度一致）：**
- 引出方法："为了解决上述问题，本文建立了..."
- 问题间过渡："在问题一的基础上，进一步考虑..."
- 引出算法："基于以上分析，本文提出..."
- 引出结果："计算结果如下表所示"
- 问题引入："针对问题X，..."

**逻辑连接词：**
- 并列："首先...其次...最后..."
- 递进："不仅...而且..."、"在...基础上进一步..."
- 因果："由于...因此..."、"考虑到..."
- 转折："虽然...但是..."、"尽管如此..."

**公式间衔接：**
- "其中，xxx表示..."
- "代入式(n)可得..."
- "联立式(m)和式(n)解得..."
- "化简整理得到..."

### 3.2 团队思考痕迹

**获奖论文通过以下方式展现思考过程（而非直接给答案）：**

1. **难点分析**：建模前分析问题难点和关键点
   > "由于太阳光入射方向和镜面法向量不在同一坐标系中，需要建立坐标变换关系..."

2. **方法对比**：简要对比不同方法优劣，说明选择理由
   > "由于数据不满足正态分布，选择Spearman而非Pearson做相关性分析"
   > "由于数据存在节假日效应，选择Prophet而非ARIMA"

3. **分步推导**：复杂公式分步骤推导，展示思考路径

4. **结果解释**：给出结果后解释物理意义和变化规律
   > "6月最高、12月最低，与太阳高度角变化一致"

5. **试错痕迹**：体现"先简化后推广"的思路
   > "最初尝试线性拟合时R²仅0.72，残差图显示明显的非线性趋势，因此改用二次多项式拟合"

### 3.3 图表标注规范

**图标注：**
- 格式："图N XXXXX"（居中，位于图下方）
- 图号全篇连续编号（图1、图2、...）
- 子图标注："图N(a) XXX"，"(a)"位于子图下方
- 坐标轴标注含单位（如"距离/m"、"效率/%"）
- 多曲线图使用图例区分不同参数取值

**表标注：**
- 格式："表N XXXXX"（居中，位于表上方）
- 表号全篇连续编号（表1、表2、...）
- 三线表格式（顶线1pt + 表头下线0.5pt + 底线1pt，无竖线无行线）
- 数值小数点对齐

**灵敏度分析图特别规范：**
- 用虚线标注约束阈值（如10%、20%覆盖率基准线）
- 参数变化范围覆盖题目给定范围的上下界

### 3.4 参考文献规范

**参考文献来源组合：**
- 国标/规范（B题必引，如GB 12327-1998海道测量规范）
- 方法的原始论文（如NSGA-II原始论文、M-K检验文献）
- 应用领域期刊论文
- 经典教材（如优化方法、数理统计教材）
- 往届相关论文

**格式：GB/T 7714-2015**
- 期刊：[1] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
- 图书：[2] 作者. 书名[M]. 出版地: 出版社, 年.
- 学位论文：[3] 作者. 题名[D]. 保存地: 保存单位, 年.
- 标准：[4] 标准编号, 标准名称[S].

## 四、获奖论文评分要素对照表

| 评分要素 | 获奖论文做法 | 常见失分点 |
|---------|-------------|-----------|
| 摘要 | 每问含具体数值，方法名称明确 | 摘要无数字、方法描述模糊 |
| 问题分析 | 独立成章+技术路线图 | 直接跳到建模，无分析过程 |
| 模型假设 | 4-9条，每条附理由 | 假设过多/过少，无理由说明 |
| 公式推导 | 20-60个编号公式，逐步推导 | 公式无编号、跳步严重 |
| 符号说明 | 三线表，含单位 | 用行内文字、无单位 |
| 结果展示 | 表格+图+分析三位一体 | 只有数字无图表，或有图表无分析 |
| 灵敏度分析 | 独立章节，2-3参数，含图 | 完全缺失或仅文字描述 |
| 模型评价 | 优点+缺点+推广三段式 | 只写优点不写缺点，或缺点过于自贬 |
| 参考文献 | 4-10篇，含国标/教材/方法文献 | 不足3篇、格式不规范 |
| 代码附录 | 完整可运行，中文注释 | 无代码或代码不完整 |

## 五、可复用的建模流程模板

### 5.1 通用建模流程（适用于所有题型）

```
Phase 1: 破题
  ├── 读取赛题，提取子问题
  ├── 识别每个子问题的数学本质
  ├── 扫描历史真题找相似题
  └── 圈定候选方法（5-8个）

Phase 2: 建模
  ├── 建立坐标系/变量体系
  ├── 推导核心公式（逐步编号）
  ├── 列出模型假设（4-9条）
  ├── 整理符号说明表
  └── 确定目标函数和约束条件

Phase 3: 求解
  ├── 选择算法（直接计算/优化算法/数值方法）
  ├── 编写Step式伪代码
  ├── 绘制算法流程图
  ├── 执行计算
  └── 输出结果（表格+图）

Phase 4: 验证
  ├── 结果分析（解释规律、物理意义）
  ├── 灵敏度分析（2-3参数，±20%）
  ├── 模型评价（优点+缺点+推广）
  └── 代码整理（完整可运行+注释）

Phase 5: 论文
  ├── 撰写摘要（最后写，含数值）
  ├── 填充论文骨架
  ├── 植入团队思考痕迹
  ├── 终审（编号连续性、符号一致性）
  └── 打包输出
```

### 5.2 分题型方法链

| 题型 | 方法链 | 核心算法 |
|------|--------|---------|
| A题(物理) | 坐标系→向量运算→效率分解→优化→灵敏度 | 网格搜索/GA/三分法 |
| B题(几何) | 几何推导→覆盖计算→约束优化→阈值分析 | SA/PSO/迭代递推 |
| C题(数据) | 分布检验→关联分析→预测建模→优化决策 | LSTM/Prophet/NSGA-II |
| D题(排程) | 周期分析→阶段离散化→整数规划→随机扩展 | 遍历/LP/MIP |
| E题(时序) | 回归→突变检测→季节分解→预测→决策 | SARIMA/M-K/GM(1,1) |

### 5.3 图表配置标准

| 图表类型 | 使用场景 | 数量参考 |
|---------|---------|---------|
| 技术路线图 | 问题分析章节 | 1张 |
| 算法流程图 | 每个问题的求解部分 | 每问1张 |
| 散点图/布局图 | 空间分布展示 | 2-5张 |
| 折线图 | 趋势/参数敏感性 | 5-10张 |
| 柱状图 | 逐月/逐类比较 | 3-5张 |
| 热力图 | 空间效率分布 | 1-3张 |
| 3D图 | 三维布局/曲面 | 1-3张 |
| 数据表 | 精确结果展示 | 5-15张 |
| 灵敏度图 | 参数扫描曲线 | 1-3张 |

## 六、从获奖论文中提炼的"加分项"清单

1. **多方法交叉验证** — 不只用一种方法，用2-3种方法互相验证结果
2. **模型比较与选择** — 对比多个模型（如ARIMA vs Prophet），给出选择理由
3. **数据驱动的方法选择** — 先分析数据特征再选方法，而非生硬套用
4. **3D可视化** — 镜场布局、曲面图等3D展示增加视觉冲击力
5. **Pareto前沿** — 多目标优化问题展示Pareto前沿解集
6. **国标引用** — 引用相关国标/规范增强工程依据
7. **完整可运行代码** — 附录代码可独立运行，含中文注释
8. **团队思考痕迹** — 体现试错、对比、选择的过程
9. **物理意义解释** — 结果不止于数字，解释背后的物理/业务含义
10. **隐含灵敏度显式化** — 将参数遍历结果整理为独立的灵敏度分析章节
