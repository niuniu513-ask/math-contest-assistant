## 二、按图表类型的配色方案

### 2.1 散点 + 拟合线（最常用组合）

```
散点数据：  Coral红 #E74C3C
拟合曲线：  Steel蓝 #2980B9  (线宽 1.5-2.0)
置信区间：  Steel蓝 #2980B9  (FaceAlpha 0.12-0.16)
残差参考：  浅灰   [0.5 0.5 0.5] (LineStyle "--")
```

```matlab
% 数据与拟合对比 — 获奖论文标准配色
scatter(ax, x, yData, 36, competition_colors(1,:), "filled", ...
    "MarkerEdgeColor", competition_colors(1,:)*0.7, ...
    "DisplayName", "实测数据");
hold(ax, "on");
plot(ax, xSmooth, yFit, "Color", competition_colors(2,:), ...
    "LineWidth", 1.5, "DisplayName", "模型拟合");
% 置信区间
xFill = [x; flipud(x)];
yFill = [yFit+2*sigma; flipud(yFit-2*sigma)];
fill(ax, xFill, yFill, competition_colors(2,:), ...
    "FaceAlpha", 0.12, "EdgeColor", "none");
hold(ax, "off");
```

### 2.6 热力图（相关性矩阵）

```
正相关 → 负相关：RdBu_r（红-白-蓝发散）
  - 红端 #67001F → 白 #F7F7F7 → 蓝端 #053061
  - 中心值（0相关）= 白色

感知均匀热力图（连续值）：
  - viridis / parula（禁止 jet/rainbow）
```

## 三、竞赛 vs 期刊 配色选择

| 场景 | 使用色板 | 特点 |
|------|---------|------|
| 国赛/美赛论文 | **竞赛色板** (本页) | 高对比度、适合投影和黑白打印、色觉友好 |
| SCI期刊投稿 | Nature/Wong 色板 | 低饱和度、学术克制、符合期刊规范 |
| PPT演示 | 竞赛色板 + 加深 | 加大线宽和字号、高对比度 |
| 海报展示 | 竞赛色板 | 大字号、增强对比 |

在 `apply_publication_style()` 中通过 `"profile"` 参数切换：

```matlab
style = apply_publication_style(fig, "zh", "report", "profile", "competition");  % 竞赛
style = apply_publication_style(fig, "en", "report", "profile", "nature");       % 期刊
```

## 四、获奖作品绘图"潜规则"

### 4.1 字号与线宽

| 元素 | 大小 | 说明 |
|------|------|------|
| 坐标轴标题 | 12pt | 必须包含单位和变量名 |
| 刻度标签 | 10pt | 清晰可读 |
| 图例 | 9-10pt | 不遮挡数据 |
| 面板标题 | 13-14pt bold | 短标题，完整解释在图注 |
| 数据线 | 1.5-2.0pt | 主线突出 |
| 参考线 | 0.8-1.0pt | 虚线，不抢眼 |
| 网格线 | 0.3-0.5 alpha | 若隐若现 |

### 4.2 图表尺寸（论文中实际宽度）

```
单栏图：  3.5 inch (约 8.9 cm)  — 论文半页宽
双栏图：  7.2 inch (约 18.3 cm) — 论文全页宽
报告图：  6.3 inch (约 16.0 cm) — 默认宽度
```

### 4.3 获奖作品三大标志

1. **无网格线或极淡网格** — 不使用 `grid on`；需要参考线时用 `xline`/`yline` + 图注说明
2. **白底无边框** — 白色背景、隐藏上/右边框（`box off`）
3. **色觉友好** — 红绿不共存于需要区分的两条线（红蓝替代红绿）

### 4.4 常见"评委反感"模式（避免）

| 模式 | 问题 | 修复 |
|------|------|------|
| `grid on` | 网格线干扰数据阅读 | 用 `grid off`，参考线用 `yline` |
| `jet`/`rainbow` 色图 | 制造虚假梯度 | 用 `parula`/`viridis`/`RdBu_r` |
| 3D 饼图/伪3D柱状图 | 扭曲比例感知 | 用 2D 柱状图或点图 |
| 图例超过6项 | 无法快速匹配 | 拆图或直接标注在线旁 |
| 中文字体缺失 | 显示为方框□ | `fontname` 用 SimHei/Microsoft YaHei |
| 截图式导出 | 模糊、有窗口边框 | 用 `export_publication_figure` |
| 每个点都打 marker | 稠密曲线糊成一团 | 取消 marker 或用 `MarkerIndices` |
| 非零基线柱状图 | 夸大小差异 | 默认从零开始，需截断时显式标注 |
