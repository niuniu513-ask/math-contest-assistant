# 独立质检 Agent 调度

独立质检用于发现作者盲区，不参与被审产物的编写或修正。主 Agent 维护权威文件，质检 Agent 默认只读并返回证据。

## 固定门禁

| 门禁 | 输入 | 检查重点 |
|---|---|---|
| `M1` | 题目、附件清单、分析报告、模型合同 | 子问覆盖、单位、假设、可辨识性、约束、实现和验证 |
| `P1` | 最小命令、日志、真实/等价输入、关键输出 | 从输入到结果的纵向链路、边界和独立核对 |
| `P2` | 冻结代码、结果、图、题设模板、复现清单 | 独立重跑、约束、统计/数值验证、结果完整性 |
| `W1` | Claim–Evidence Matrix、论文大纲、推导/决策/对标台账 | 主张证据、逐步推导、数值实例、双方法验证、三重敏感性、目标对齐、工程裕度和章节落点 |
| `W2` | 当届规则、最终论文、源码、编译/渲染日志、内容审计报告 | 内容一致、公式/图表/文献质量档、获奖论文隔离、纯文本公式、图表三层解读、真实决策痕迹、实际渲染和交付完整性 |

门禁后相关产物变化时原回执失效。单阶段任务只运行涉及的门禁。环境没有独立 Agent 时按对应清单自审并标记 `LIMITED`，不伪称独立 `PASS`。

## 派发输入

只给当前门禁所需的原始证据：用户要求、题目/附件路径与哈希、验收条款、权威产物、命令和日志、上一门禁回执。不要告诉质检者预期结论，也不要泄露作者的自我评价。

## 固定回执

1. `范围`：门禁与未覆盖项；
2. `输入快照`：路径和 SHA-256；
3. `状态`：`PASS`、`FAIL` 或 `BLOCKED`；
4. `证据`：命令、退出码、来源、页码、文件和关键数值；
5. `发现`：`P0` 正确性/官方硬约束、`P1` 复现/一致性、`P2` 非阻塞改进；
6. `返工`：返回状态机的阶段、必须修正项和复验入口。

存在未解决的 P0/P1 时返回 `FAIL`；缺少不可替代输入、依赖或权限时返回 `BLOCKED`。主 Agent 不得口头覆盖。

## 可选协作

仅当用户明确要求额外协作时，可并行官方规则核验、附件盘点、文献调研、隔离算法原型或独立实验。不要让多个 Agent 同时修改权威模型、代码、结果或论文；不要按章节多人拼写论文。
