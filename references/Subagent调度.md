# 独立质检 Agent 调度

独立质检用于发现作者盲区，不参与被审产物的编写或修正。主 Agent 维护权威文件，质检 Agent 默认只读并返回证据。

## 固定门禁

| 门禁 | 输入 | 检查重点 |
|---|---|---|
| `M1` | 题目、附件清单、分析报告、模型合同 | 子问覆盖、单位、假设、可辨识性、约束、实现和验证 |
| `P1` | 最小命令、日志、真实/等价输入、关键输出 | 从输入到结果的纵向链路、边界和独立核对 |
| `P2` | 冻结代码、结果、图、题设模板、复现清单 | 独立重跑、约束、统计/数值验证、结果完整性 |
| `W1` | Claim–Evidence Matrix、论文大纲、推导/决策/对标台账 | 每个摘要/结论/正文关键主张逐行绑定直接证据；逐步推导、数值实例、双方法验证、三重敏感性、目标对齐、工程裕度和章节落点 |
| `W2` | 当届规则、最终论文、源码、编译/渲染日志、内容审计报告 | 内容一致、公式/图表/文献质量档、获奖论文隔离、纯文本公式、图表三层解读、真实决策痕迹、实际渲染和交付完整性 |

门禁后相关产物变化时原回执失效。单阶段任务只运行涉及的门禁。环境没有独立 Agent 时按对应清单自审并标记 `LIMITED`，不伪称独立 `PASS`。

## 派发输入

只给当前门禁所需的原始证据：用户要求、题目/附件路径与哈希、验收条款、权威产物、命令和日志、上一门禁回执。不要告诉质检者预期结论，也不要泄露作者的自我评价。

## 固定回执

1. `范围`：门禁与未覆盖项；
2. `输入快照`：路径和 SHA-256；
3. `状态`：`PASS`、`FAIL` 或 `BLOCKED`；
4. `证据`：命令、退出码、来源、页码、文件和关键数值；
5. `发现`：`P0` 正确性/官方硬约束、`P1` 复现/一致性、`P2` 非阻塞改进；
6. `返工`：返回状态机的阶段、必须修正项和复验入口。

存在未解决的 P0/P1 时返回 `FAIL`；缺少不可替代输入、依赖或权限时返回 `BLOCKED`。主 Agent 不得口头覆盖。

## 语言对比 Agent

进入 `prototype` 前（`M1` 后）必须完成 Python vs MATLAB 选型。环境支持 Subagent 时派发独立对比 Agent：输入题目、模型合同候选语言与两种语言的评分卡（`references/语言选型对比.md`），输出逐项比较、`chosen`/`runner_up`/`deciding_reason` 与参考图语言，写回合同 `language_selection`；不把偏好或作者自评泄露给对比者。环境不支持时按评分卡自评并标记 `LIMITED`，不得伪称独立对比。

## 可选协作菜单

以下协作默认关闭，仅当用户明确启用时运行：

| 协作项 | 输入 | 输出 |
|---|---|---|
| 官方规则核验 | 竞赛、届次、模板需求 | 官方 URL、适用届次、硬约束、模板路径和哈希 |
| 附件盘点 | 题目附件 | 文件哈希、工作表/页码、字段、行列、缺失和异常 |
| 文献与模型族调研 | 主张、关键词、候选模型 | 题名、作者、年份、DOI/出版页、理论公式、适用条件和风险 |
| 隔离算法原型 | 已冻结的候选算法 | 最小代码、运行命令、真实输出、限制和未解决问题 |
| 独立实验批次 | 已冻结的模型、指标和参数范围 | 参数、种子、命令、结果文件、耗时和失败记录 |
| Python/MATLAB 对照实现 | 同一模型合同和输入输出 | 两种语言的关键数值、差异和复现命令 |
| 术语与英文表达核验 | 术语表、目标语言和论文草稿 | 术语、符号、单位和英文表达核对 |

不要让多个 Agent 同时修改权威模型、代码、结果或论文；不要按章节多人拼写论文。可选协作者只返回证据、实验产物或建议，主 Agent 负责整合和复验。
