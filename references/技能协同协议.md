# 外部 Skill 协同协议

## 1. 总原则

按阶段加载能力，不一次性加载全部 Skill。主流程、模型合同、权威结果和门禁状态始终由本 Skill 管理；外部 Skill 提供专门能力，不得绕过证据链或修改已冻结事实。

| 阶段 | 必要 Skill | 职责 | 退出证据 |
|---|---|---|---|
| 联网研究 | `web-access` | 获取官方规则、原始数据页、原始论文与权威说明 | URL、标题、发布者、访问日期、关键定位与本地摘录 |
| 科学计算 | `scientific-toolkit-skill` | 选择并实现 Python/MATLAB 科学计算、统计、优化、仿真和绘图 | 可运行代码、版本/依赖、日志、权威结果和图 |
| 论文起草 | `research-writing-skill` | 将模型合同和真实结果写成证据式学术文本 | Claim–Evidence Matrix 全覆盖的正文 |
| Word/展示排版 | `office-academic-skill` | 使用官方模板生成或检查 DOCX/PPT，执行版面质量检查 | 可编辑文件、渲染件和逐页检查记录 |
| 终稿自然化 | `humanizer_academic` | 降低机械化措辞和句式同质性 | 事实不变的润色稿与差异审计 |

若当前环境缺少其中一个 Skill，记录 `BLOCKED` 或使用本 Skill 的对应内置流程；不得假装已经调用。

## 2. 联网取证：web-access

所有联网搜索、网页提取、登录态浏览和动态页面操作均先加载 `web-access` 并遵循其安全提示。优先访问主办方、政府/机构、数据发布者、论文出版页和官方文档；搜索结果只用于定位，不直接作为事实证明。

把每条外部证据写入来源表：`source_id`、URL、页面标题、发布者、发布日期/版本、访问日期、支持的主张、页面段落/表格/图号或下载文件哈希。需要登录态或可能包含隐私的数据不得擅自上传或外传。

## 3. 科学计算：scientific-toolkit-skill

进入 `prototype` 前加载 `scientific-toolkit-skill`，再按实际模型选择其 MATLAB、NumPy/SciPy、统计、机器学习、优化、仿真、网络或可视化引用。它负责实现质量，本 Skill 的模型合同和 P1/P2 门禁负责数学正确性。

- Python 与 MATLAB 同等重要；按 `references/语言选型对比.md` 对当前题完成对比选型后统一使用，不设固定主路线。
- 优先成熟库，记录版本、随机种子、单位、数组维度、容差和退出状态。
- 数据图由求解语言运行代码生成；**参考图/示意图/流程图统一用 MATLAB 绘制**（`MATLAB示意图绘制规范.md`）；每个核心模型至少有必要演示/实例图及结果证据。
- 任何外部 Skill 的示例参数都不能冒充题目参数或计算结果。

## 4. 学术写作：research-writing-skill

仅在 P2 冻结后加载 `research-writing-skill`。沿用本 Skill 的论文写作工作流和官方模板，将模型合同、来源表、结果表、验证矩阵和图表写成正文。篇幅按官方规则、用户要求和证据完整性确定，不设默认最低页数。

写作时区分题设事实、外部文献、模型假设、计算结果和解释性推断；不得补写未运行的实验、未检索的引用或不存在的 DOI。`research-writing-skill` 的通用章节建议服从竞赛模板和逐问证据闭环。

## 5. 排版：office-academic-skill

目标为 Word、PPT 或 Office 模板时加载 `office-academic-skill`，同时按文件类型加载本 Skill 的 DOCX/LaTeX 工具。不得覆盖用户原模板；在复制件中排版。完成后检查中文字体、公式、表格、图片比例、分页、页眉页脚、交叉引用和残留占位符，并渲染逐页查看。

论文主体与附件单独计页，按当届规则和用户要求检查；代码和原始明细附件不混入主体统计。

## 6. 终稿自然化：humanizer_academic

只在技术事实、引用和版面结构冻结后运行。该 Skill 原本面向医学论文，本项目只迁移通用规则：调整句长节奏、减少句式重复、保持术语一致、删除空泛拔高和同义反复、保留必要逻辑连接。

不得套用医学作者画像，不得为了“降低AI率”改写公式、变量、数值、单位、图表编号、引用、模型条件或结论强度。润色后对以下内容做机器/人工差异审计：

1. 所有数字、百分比、区间、单位和公式前后一致；
2. 技术术语与符号表一致；
3. 引用键、图表编号和主张映射未改变；
4. 未新增无证据的因果、显著、最优或鲁棒表述；
5. 每段句式有自然变化但逻辑连接完整。

任何事实差异都退回润色前版本修复，不能带差异进入 W2。
