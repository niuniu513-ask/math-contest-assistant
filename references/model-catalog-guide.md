# 数学建模常用方法分类与选择指南

## 方法分类索引

| 方法 | 适用场景 | 数据需求 | 复杂度 |
|------|----------|----------|--------|
| 线性回归 | 线性关系预测 | 小-中 | 低 |
| 多元线性回归 | 多变量线性关系 | 中 | 低 |

## 模型选择决策树

```
1. 问题核心是什么？
   ├── 预测某个量
   │   ├── 有时序成分 → ARIMA / SARIMA / LSTM / 灰色预测
   │   ├── 多特征输入 → 回归 / XGBoost / 神经网络
   │   └── 小样本 → 灰色预测 / SVR / 贝叶斯
   ├── 寻找最优方案
   │   ├── 约束和目标都是线性 → 线性规划
   │   ├── 含整数/离散变量 → 整数规划 / 0-1规划
   │   ├── 多阶段决策 → 动态规划
   │   └── 复杂/非光滑 → 遗传算法 / PSO / 模拟退火
   ├── 评价/排序
   │   ├── 有主观判断 → AHP + 熵权法 组合
   │   ├── 纯数据驱动 → TOPSIS / 主成分分析 / DEA
   │   └── 模糊/定性指标 → 模糊综合评价
   ├── 分类/分组
   │   ├── 有标签(分类) → SVM / 决策树 / 贝叶斯
   │   └── 无标签(聚类) → K-means / DBSCAN / 层次聚类
   ├── 网络/路径优化
   │   └── → Dijkstra / 最大流 / 最小生成树 / TSP算法
   ├── 动态变化过程
   │   ├── 连续时间 → ODE / PDE
   │   └── 离散时间 → 元胞自动机 / 马尔可夫链
   └── 含随机性
       └── → 蒙特卡洛 / MCMC / 贝叶斯推断
```

## 常见组合策略

1. **预测 + 优化**：先预测（回归/时间序列），再基于预测做优化（线性规划/动态规划）
2. **评价 + 聚类**：先用评价方法（TOPSIS/AHP）打分，再用聚类分组
3. **降维 + 分类**：PCA 降维后做分类/聚类
4. **模拟 + 优化**：蒙特卡洛模拟生成场景，在每个场景下优化
5. **微分方程 + 参数优化**：ODE 建模后进行参数估计（最小二乘/遗传算法）
