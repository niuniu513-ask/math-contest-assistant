## 1. 决策权限

Agent 可自行决定模型、语言、算法、验证方法、图表和单一交付格式，只要决定不改变用户目标、可由现有证据支持且可回退。

在以下情形暂停：

- 缺少不可替代的题目页、附件、密码或官方模板；
- 两个解释会改变所求对象，无法由题目、附件或规则消歧；
- 需要联网、安装依赖、发送信息或执行高风险写操作的新授权；
- `M1` 通过后等待用户确认建模方案；
- 用户要求其他阶段确认。

问题可以暂时隔离时，在状态文件中记为 `open_issue`，继续不受影响的子问题。

### 强制建模确认

`M1` 通过后，向用户提供一份可决策摘要：

1. 每个子问题选用的模型及前后依赖；
2. 关键变量、目标、约束和假设；
3. Python/MATLAB及核心算法选择；
4. 演示/实例图规划与验证方案；
5. 主要失败风险、备选模型和预计代价。

最后明确询问用户是否进入编程求解。用户回复确认后，把确认时间、确认范围和任何修改意见写入 `decisions`，再执行 `project_state.py advance --to prototype`。用户要求调整时更新模型合同并重跑 `M1`。用户在任务开始时明确要求跳过确认并直接完成时，可将该授权记录后继续。

## 2. 状态与检查点

`.work/run-state.json` 是流程状态，不是论文证据。至少记录：

- `mode`：`full`、`model`、`code`、`paper`；
- `stage`：主 Skill 状态机中的当前状态；
- `competition`、`year`、`problem_id`；
- `assumptions`、`open_issues`、`decisions`；
- `artifacts`：路径、SHA-256、用途；
- `gates`：状态、证据路径、时间；
- `next_action`。

每次满足以下任一条件时更新状态：读取完题目、模型合同冻结、最小链路通过、全量结果冻结、论文证据大纲冻结、格式交付通过。

用户确认后的阶段推进示例：

```powershell
python "<SKILL_ROOT>/scripts/project_state.py" advance `
  --project-root "<PROJECT_ROOT>" --to prototype `
  --gate M1 --gate-status PASS `
  --evidence ".work/model-contract.json" `
  --user-approval "用户在当前回合确认按推荐方案进入编程" `
  --next-action "运行问题一最小实例"
```

## 3. 时间预算

未给定截止时间时使用完整模式。已知剩余时间时先保底再增益：

| 剩余时间 | 策略 |
|---|---|
| 充足 | 主模型、必要对比、完整稳健性、目标格式 |
| 紧张 | 先完成全部子问的可信基线，再强化高权重问题 |
| 极短 | 保证可行解、题目指定输出、复现和证据一致性；省略装饰性工作 |

无论时间多短，不省略真实运行、结果追溯和题目指定文件。

## 4. 门禁证据

### M1 模型合同

- 全部子问已覆盖；变量、单位、目标、约束和输出明确；
- 模型假设与数据相容；有基线、验证和失败回退；
- 可由可用环境实现。

### P1 最小纵向切片

- 使用真实输入或结构等价小实例；
- 命令退出码为 0；输出可从输入追溯；
- 至少一个手算、极限、基线或独立实现核对通过。

### P2 全量结果

- 全部子问已运行；题设约束和模板已检查；
- 统计验证、数值验证或优化验证与模型类型匹配；
- 复现清单中的哈希、参数、依赖和命令有效。

### W1 证据大纲

- 每个摘要和结论主张有结果路径；
- 每个公式、表、图有章节落点和来源；
- 不确定性、局限和对比结论与验证相符。
- 推导台账、真实决策痕迹和内部对标差距完整；
- 双方法交叉验证、三重敏感性、物理/优化目标对齐、工程裕度和必要视觉证据已有真实结果。

### W2 交付

- 官方规则和模板优先级正确；
- 数值、单位、符号、编号、引用和附件一致；
- 完整竞赛论文的 15 公式、12 图、8 文献深度质量档通过；
- `paper_content_audit.py --strict` 通过，正文无获奖论文泄漏、纯文本公式、模板图表句或虚构团队痕迹；
- 文件真实生成/编译并完成最终视觉检查。

## 5. 恢复策略

先运行 `project_state.py status`。若状态文件和产物哈希一致，从 `next_action` 继续；若证据产物变化，退回依赖它的最早门禁。保留失败日志，不用同名“最终版2”“最终版3”绕过一致性检查。
